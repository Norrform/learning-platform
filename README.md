# Learnly — Expanded Product Demo

A responsive, multi-page front-end prototype for an adaptive learning platform.

## Live demo
https://learnly-learning-demo.vercel.app

## Run locally
No build tools or dependencies are required. Clone or download this repository, then open \`index.html\` in a browser.

## Included in this demo
- Overview dashboard with learning stats, streak, active paths, and recommendations
- Learning path creation flow with a sample roadmap
- My learning page with all / in-progress / completed filters
- Discover page with search, topic categories, and save controls
- Lesson experience with Read, Practice, simulated AI tutor, and personal notes tabs
- Flashcards with three sample decks, flip controls, and self-rating
- Study groups with join / leave interactions and create-group flow
- Community feed with sample posts, likes, and a local post composer
- Saved resources collection
- Notes area with editable notes stored in browser local storage
- Settings preferences
- Responsive desktop, tablet, and mobile layouts
- Demo interactions and local persistence for notes, saved resources, joined groups, likes, and custom paths

## Important limitations
This is a front-end concept demo, not a production learning service.
- Roadmaps and lesson content are sample/demo logic, not generated by AI.
- The tutor is simulated and is not connected to a model.
- No real accounts, cloud database, collaboration, moderation, payments, or external-source retrieval are connected.
- Local demo data is stored only in the current browser using localStorage. It is not synced between devices.
- Community members and group activity are fictional sample content.

## Product areas worth validating
1. Does the adaptive learning path feel understandable and motivating?
2. Are the lesson modes (read, practise, tutor, notes) easy to discover?
3. Are progress and mastery insights genuinely useful?
4. Do learners want flashcards and groups inside the same workspace?
5. Which features feel essential for a first release versus later versions?

## Suggested build sequence
1. Real user accounts and database persistence.
2. AI learning planner that creates one module at a time.
3. Lesson generation and tutor grounded in the active module.
4. Exercises, answer evaluation, concept-level mastery, and review scheduling.
5. Trusted-source retrieval with citations and quality checks.
6. Study groups, sharing, moderation, and notifications.
7. Subscription and advertising decisions after user testing.
