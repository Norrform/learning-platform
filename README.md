# Learnly — Learning Platform Demo

A responsive, interactive front-end concept for an AI-powered learning platform.

## Run locally

No build tools or dependencies are required.

1. Download or clone this repository.
2. Open `index.html` in your browser.

## What's included

- Dashboard overview with sample active learning paths
- Learning goal form with level and daily-time preferences
- Editable sample roadmap modal
- Lesson modal with Read, Practice, and Ask AI Tutor tabs
- Responsive layout for desktop, tablet, and mobile

## Demo limitations

This is a static front-end prototype. The roadmap uses sample logic; the AI tutor is not connected to an AI model; accounts, database storage, and progress persistence are not implemented.
